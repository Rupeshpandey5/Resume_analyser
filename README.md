# AI Resume Analyzer

AI Resume Analyzer built using Flask + Python + Gemini AI.


- ## 🚀 Live Demo

🔗 https://resume-analyser-hfl6.onrender.com

## ✨ Features

- Upload PDF Resume
- ATS Score
- Skill Extraction
- Missing Skills Detection
- AI Resume Analysis
- Interview Questions
- Responsive UI

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- PyMuPDF
- OpenRouter API
