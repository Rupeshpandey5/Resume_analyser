# AI Resume Analyzer

AI Resume Analyzer built using Flask + Python + Gemini AI.

## Features

- Resume Upload
- PDF Parsing
- Skill Extraction
- ATS Score
- Missing Skills
- AI Suggestions
- Resume Summary
- Interview Questions
- Job Recommendation

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```
